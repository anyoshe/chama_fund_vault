# Install ChamaVault as an app

Requires **HTTPS** (Vercel production URL).

## Android (Chrome)
1. Open the live site
2. Menu ⋮ → **Install app** or **Add to Home screen**
3. Open from the home screen icon (runs full screen)

## iPhone (Safari)
1. Open the live site in **Safari**
2. Share → **Add to Home Screen**
3. Open the icon (standalone-style)

## Desktop (Chrome / Edge)
1. Open the live site
2. Install icon in the address bar, or Menu → **Install ChamaVault**

Offline: shell may load; live data still needs network (Supabase).
