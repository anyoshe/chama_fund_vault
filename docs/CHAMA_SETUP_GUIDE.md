# New chama setup (self-guided)

After **Register chama**, the Chairperson sees an in-app checklist until core steps are done.

## Order

1. **Pots** — Settings: tick only kits this group uses  
2. **Payment mode** — Manual and/or M-Pesa; set “pay to” for cash/till  
3. **Contribution plans** — Amount, frequency, due day/weekday, destination pot  
4. **People** — Add members; assign Treasurer (and Secretary)  
5. **Late fines** (optional) — % + grace days  

Then: members **Pay** → Treasurer **approves** manual payments → pots update.  
Loans: request → **vote** → Treasurer **disburses** → repay.

Hide the guide with **Setup complete** when steps 1–4 are done.
